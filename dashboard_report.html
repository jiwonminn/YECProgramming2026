EV Charging Dashboard
Report summary (from report.py)

The same totals python main.py prints in the terminal, for the rows that count.

Cars charging by hour
Bars: cars receiving power. Line: cars parked (arrived, not yet departed).
CO2 released by charging, hour by hour
Each row is a charger, each column an hour. The number in a cell is the kg of CO2 released by that charger while a car was charging. Darker red means more CO2, grey means the charger was idle. Hover a cell to see the car and its power. The first row is how dirty the grid is that hour (kg CO2 per kWh); the last row is the total per hour.
Forecast: cost of 1 kWh by hour
Electricity price plus the carbon cost of that hour's grid CO2. Outlined: the blue segment marks the cheapest hour, the grey segment the cleanest.
